# Dhruv-Setu CRM

A responsive, browser-based tourism CRM prototype with role-based dashboards, dynamic docket fields, report exports and mail configuration.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any static server.

## Demo accounts

- User: `user` / `user123`
- Support: `support` / `support123`
- Admin: `admin` / `admin123`

Data persists in browser `localStorage`. Production authentication, database storage, SMTP delivery and dialer integration should be connected through a secure backend API.
